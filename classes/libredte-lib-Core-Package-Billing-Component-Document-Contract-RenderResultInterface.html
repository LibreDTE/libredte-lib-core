public toArray() : array<string|int, mixed>

A diferencia de getRenderings(), esta representación sí se expande por cantidad de copias: cada archivo con copies > 1 aparece como múltiples entradas (mismo content/mimeType, calculados una sola vez), cada una con un copyNumber (desde 1) y, si hay más de una copia, el filename ajustado para no colisionar entre copias.
