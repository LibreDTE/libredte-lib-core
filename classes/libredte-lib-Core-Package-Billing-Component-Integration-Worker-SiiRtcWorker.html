Attributes
#[Operation]
$name: 'check_aec_sent_status'
$summary: 'Consulta el estado de un AEC enviado al SII'
$description: <<<'MD' Obtiene el estado actualizado del envío de un AEC al Registro de Transferencias de Créditos (RTC) del SII. El estado puede no ser el final: en ese caso se debe repetir la consulta más adelante. ## Cómo se usa Se envían los datos de conexión en `request` y el `trackId` que entregó `billing.integration.sii_rtc::send_aec`. No hace falta indicar la empresa: el token de la solicitud identifica al contribuyente. ## Estados (`status`) | Valor | Significado | |---|---| | `UPL` | Envío en proceso de upload | | `RCP` | Envío recibido | | `RSC` | Rechazado por error en el esquema | | `SOK` | Esquema validado | | `RFS` | Rechazado por firma del sobre | | `FSO` | Firma del sobre validada | | `RCR` | Error en la carátula | | `COK` | Carátula OK | | `VDC` | Validación de documento | | `RDC` | Documento inválido | | `VCS` | Validación de cesiones | | `RCS` | Cesión inválida | | `EOK` | Envío aceptado | | `EAN` | Envío anulado | Son estados de error `RSC`, `RFS`, `RCR`, `RDC` y `RCS`. El estado es final cuando es de error, o es `EOK` o `EAN`: el SII ya no procesará más el envío. Cuando el SII no encuentra información del envío, `status` trae un código de error propio del SII. Detalle del servicio del SII: [Consulta Estado Envío de AEC al Registro](https://www.sii.cl/factura_electronica/ws_consulta_estado_aec.pdf). MD
$parameters: ['request' => ['description' => self::REQUEST_DESCRIPTION, 'example' => ['certificate' => ['certificate' => '', 'privateKey' => ''], 'options' => ['environment' => 1]]], 'trackId' => ['description' => 'Número de seguimiento (Track ID) que asignó el SII al envío del AEC.', 'example' => 1234567890]]
$results: ['success' => ['description' => <<<'MD' Estado del envío. `status` es uno de los estados de arriba (o un código de error del SII), `description` su explicación, `error` indica si es un error y `final` si es un estado final. El ejemplo muestra la respuesta cuando el SII no encuentra información del envío. MD, 'example' => ['track_id' => 1234567890, 'status' => '2', 'description' => 'Error: no se encontró información.', 'error' => true, 'final' => false]]]
