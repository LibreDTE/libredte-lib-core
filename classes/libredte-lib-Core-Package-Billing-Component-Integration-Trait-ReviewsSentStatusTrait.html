ReviewsSentStatusTrait

ReviewsSentStatusTrait.php : 36

Trait que implementa la revisión del estado de un envío a partir de los datos normalizados de la respuesta (`getData()`).

Se apoya en las claves status, description y resume de los datos. Lo que depende del catálogo de códigos de cada API del SII (DTE o boletas) lo deben implementar las clases que usen el trait.
