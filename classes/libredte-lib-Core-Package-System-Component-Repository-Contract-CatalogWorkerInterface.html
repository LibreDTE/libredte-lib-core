CatalogWorkerInterface extends WorkerInterface
in
  • LibreDTE

CatalogWorkerInterface.php : 39

Interfaz para la exploración genérica de repositorios de datos.

No depende de ninguna entidad o repositorio específico: cualquier repositorio registrado en el RepositoryManagerInterface de la aplicación puede consultarse a través de este worker, identificándolo por su FQCN (clase de entidad o interfaz), tal como se usa con RepositoryManagerInterface::getRepository().
